## À Propos

ASNL TECH est une plateforme de consultation spécialisée dans l'implémentation, la migration et l'intégration d'**Odoo**. 

Nous accompagnons les entreprises de bout en bout :
- **Audit & Optimisation** - Analyse complète de votre instance Odoo
- **Migration** - Upgrade sécurisé vers Odoo v16-v19
- **Intégrations** - Connexion Odoo à Shopify, WooCommerce, CRM, ERP
- **Support & Maintenance** - Assistance technique et évolutive
- **Formation** - Montée en compétence de vos équipes
- **Implémentation Métier** - CRM, Ventes, Stock, Comptabilité, POS, MRP

## Déploiement

### Prérequis
- Serveur web (Apache, Nginx, etc.)
- Navigateur web moderne

### Installation
1. Cloner ou télécharger le projet
2. Placer les fichiers dans le répertoire web
3. Accéder via votre domaine

### Configuration
- Modifier les coordonnées dans `index.html`
- Adapter les couleurs et images dans `assets/css/main.sass`
- Personnaliser le contenu des services
